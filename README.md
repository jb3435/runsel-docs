# runsel-docs

Runsel의 법적 고지 페이지. GitHub Pages(Jekyll)가 마크다운을 그대로 렌더한다.

**마크다운이 원본이다.** HTML을 따로 두지 않는다 — 두 벌이 되면 반드시
한쪽만 고쳐진다.

이 폴더는 앱 저장소(`myrun-log`)의 `legal/`에서 관리하고, 공개 저장소
`runsel-docs`로 내보낸다. 앱이 저장하는 항목이 바뀌면 **처리방침도 같이
고쳐야 한다** — 스키마를 바꾸는 커밋에서 함께 본다.

| 파일 | 쓰이는 곳 |
|---|---|
| `privacy.md` | App Store Connect의 개인정보 처리방침 URL (필수) |
| `terms.md` | 앱 내 링크 |
| `account-deletion.md` | 지원 URL, 심사 지침 5.1.1(v) 설명 |
